# BUG 修复与交互优化说明

## 已修复

- **布局保存竞争**：同一状态存储实例通过异步信号量串行写入；在首次等待前生成状态快照，避免 UI 编辑修改异步序列化中的集合。临时文件使用唯一名称并在失败时清理。
- **备份可靠性**：已有布局使用原子替换；主文件损坏时不再覆盖健康备份。首次保存仍采用同目录重命名。
- **异常状态数据**：清理 JSON 中的空分区、空项目，修复重复 ID，避免加载崩溃或移动项目时身份混淆。
- **桌面监听退出竞争**：对定时器调度与释放加锁，避免释放后调用 Change；文件监听缓冲区错误会安排全量刷新。
- **列表裁切**：根据 ScrollViewer 实际视口和项目外边距计算行宽；分区缩放时只更新宽度，不重建图标。
- **拖入文件夹时内容抖动**：固定边框厚度，保留高亮而不改变内容内边距。
- **浅色主题标题编辑**：光标颜色跟随前景，避免白色光标看不清。
- **主按钮悬停对比度**：独立按钮模板保留强调色，不再被通用透明悬停背景覆盖。

## UI 与体验

- 图标悬停采用 110ms 色彩过渡，浅色主题使用独立悬停色。
- 标题过渡与新增悬停效果尊重 Windows 的客户端动画设置。
- 分区标题按钮在键盘焦点进入时显示，并提供焦点边框和辅助功能名称。
- 细滚动条保持 3px 视觉宽度，命中区域扩大至 12px。
- 空分区显示可换行的拖入、新建、整理提示。
- 工具栏、主按钮统一焦点反馈；提示浮层采用圆角及动态菜单配色。

## 仍需实机验收

1. 跨分区拖动、同区排序、拖入文件夹、Esc 取消拖动，并检查选中项与最终位置。
2. 缩放列表分区、折叠展开、相邻分区联动，确认窄宽度下文字不超出视口。
3. 浅色/深色主题下检查主按钮、悬停效果、标题输入光标；Tab 导航到标题操作按钮。
4. 多显示器、不同 DPI、显示器热插拔、Explorer 重启及托盘退出。
5. 桌面文件批量变动期间退出应用，以及连续修改布局后立即退出再启动。

本轮是针对已检查路径的修复，不代表全项目不存在其他 BUG。未进行真实桌面端到端操作或视觉截图验收。信号量保证同一存储实例内的保存串行，不提供多个应用进程之间的布局合并。
