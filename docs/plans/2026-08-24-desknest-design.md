# 栖格（DeskNest）设计文档

## 1. 产品目标

栖格是一款面向 Windows 10/11 的轻量桌面图标分区工具。它在桌面壁纸层显示可拖动、可缩放、可折叠的 Fluent 风格分类盒子，用安全映射整理桌面项目，不移动、删除或重命名真实文件。

MVP 提供：桌面分区盒子、文件拖入、盒子间移动、双击打开、右键定位/移出、一键智能分类、布局锁定、原桌面图标临时隐藏、托盘运行、布局持久化和 Explorer 重启后的桌面重新挂载。

## 2. 体验与视觉

- 暂定名：栖格 · DeskNest。
- 视觉方向：克制的 Windows 11 Fluent，半透明深色面板、12px 圆角、细描边、柔和阴影、系统强调色。
- 桌面顶部提供胶囊工具条：新建分区、一键整理、锁定布局、显示/隐藏图标、设置。
- 分区标题显示名称、数量、折叠和更多操作；内容以自适应图标网格展示。
- 首次启动自动创建“常用软件、工作文档、图片素材、文件夹、临时文件”五个分区。
- 动画只用于悬停、选中和展开，空闲时不持续刷新。

## 3. 架构

采用 C#、.NET 8、WPF 与 Win32 API 的单进程分层单体：

```text
WPF Fluent UI
  ├─ MainWindow / ZoneCard / SettingsWindow
  ├─ DesktopHost / TrayService / ShellIconService
  └─ AppController
       ├─ RuleClassifier / DesktopScanner
       ├─ DesktopWatcher
       └─ JsonStateStore
```

- `DesktopHost` 将 WPF 无边框窗口挂载到 Explorer `WorkerW` 桌面层；失败时保留置底无边框窗口。
- `RuleClassifier` 完全本地按扩展名分类，不联网、不使用 AI 模型。
- `JsonStateStore` 将状态写入 `%LocalAppData%\DeskNest\state.json`，采用临时文件 + 备份的安全写入策略。
- `DesktopWatcher` 监听用户桌面与公共桌面的新增、删除和重命名，并防抖刷新映射状态。
- `ShellIconService` 通过 Windows Shell 获取文件原生图标；双击通过系统默认程序打开。

## 4. 数据模型

`AppState` 包含版本号、主题、透明度、图标尺寸、布局锁定状态、原图标隐藏状态和分区列表。每个 `Zone` 保存 ID、名称、颜色、位置、尺寸、折叠状态及映射项目。每个映射只保存 ID、规范化绝对路径、显示名称和所属分类，不复制文件内容。

## 5. 可靠性与安全

- 分类、移出分区和删除分区都只改变映射。
- 文件不存在时显示失效状态，不自动删除真实数据。
- 加载失败时尝试 `.bak`，仍失败则恢复默认布局。
- 隐藏桌面图标前记录原状态；退出和下次启动时可恢复。
- 使用命名互斥体限制单实例。
- 不需要管理员权限，不联网，不收集遥测。

## 6. 性能与验收

- 框架依赖发布包目标小于 80 MB。
- 空闲 CPU 接近 0%，内存目标 50–90 MB。
- 冷启动目标 2 秒内。
- 100 个映射下保持顺畅拖拽。
- Windows 10/11、100%/125%/150% 缩放可用。
- MVP 以单显示器为完整支持基线，多显示器保证基本可用。
