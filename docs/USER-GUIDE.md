# 栖格 · DeskNest 使用指南

## 下载与安装

从 [GitHub Releases](https://github.com/13075061852/desktop-ui/releases/latest) 获取最新版。

- **安装版**：下载 `DeskNest-Setup.exe`，按向导安装到 `%LOCALAPPDATA%\Programs\DeskNest`。
- **便携版**：下载 `DeskNest-MVP-win-x64.zip`，完整解压后启动 `DeskNest.App.exe`。
- **脚本安装**：在解压目录双击 `安装栖格.cmd`，创建桌面与开始菜单快捷方式。

系统要求：Windows 10 / 11 x64，以及 **Microsoft .NET 8 Desktop Runtime (x64)**。运行时下载地址：<https://dotnet.microsoft.com/download/dotnet/8.0>。普通 .NET Runtime 或仅安装更高主版本不能替代它。安装到当前用户目录，无需管理员权限。

安装包未签名，请从项目 Release 获取并核对校验值，不要关闭系统安全防护。

## 日常操作

| 操作 | 方法 |
| --- | --- |
| 一键整理 | 扫描当前用户桌面与公共桌面，按类型创建映射 |
| 添加映射 | 从桌面或资源管理器将文件拖入分区空白区域 |
| 排序 / 跨区整理 | 拖动图标到同区其他位置，或拖到另一个分区 |
| 打开项目 | 双击图标 |
| 更多操作 | 右键图标，可定位、查看属性、重命名等 |
| 调整分区 | 拖动标题移动；拖动边缘或角落调整尺寸 |
| 修改分区名 | 双击标题；Enter 保存，Esc 取消 |
| 切换视图 | 在分区菜单中选择图标或列表 |
| 折叠 / 展开 | 点击标题区域的折叠按钮 |
| 锁定布局 | 在工具栏 / 设置中启用，避免误拖动 |
| 外观设置 | 设置主题、透明度、图标大小和壁纸等 |
| 退出软件 | 右键系统托盘中的栖格图标，选择“退出” |

开启桌面模式可临时隐藏 Explorer 原始图标。正常退出时恢复启动前的图标可见性；强制结束进程无法保证执行恢复逻辑。

## 文件安全：映射操作与真实文件操作

以下操作**不会删除真实文件**：一键整理、同区排序、跨分区移动映射、移出分区、清空映射、删除分区。

以下操作**会影响真实文件**：

- 文件菜单“重命名”：修改实际文件名。
- “删除（移入回收站）”：执行文件删除操作。
- “清空回收站”：清除回收站内容。
- 将文件拖入真实文件夹：执行文件夹接收操作，不只是更换分区。

请留意落点与菜单文字。需要仅清理桌面映射时，使用“移出分区”，不要使用“删除”。

## 更新与配置备份

1. 使用托盘菜单正常退出旧版，确保布局保存。
2. 安装最新版到原目录，或替换便携版文件。
3. 重新启动；安装文件与布局目录分离，正常覆盖安装不会主动清空布局。

配置目录：

```text
%LOCALAPPDATA%\DeskNest\
  state.json      当前布局
  state.json.bak  上一次健康布局备份（存在历史保存时）
```

主文件无法读取时，程序尝试加载备份。手动恢复前请退出程序并备份整个配置目录，再用健康备份替换 `state.json`。便携启动同样使用此配置目录，并非将布局存放在 EXE 旁边。

布局包含项目名称和本机路径，反馈问题时请先脱敏。核心桌面整理功能在本地工作，无需注册账号。

## 常见问题

### 提示缺少运行时 / 无法启动

安装 **.NET 8 Desktop Runtime x64**，不要误装为 ARM64、x86 或仅 ASP.NET Core Runtime。完整解压 ZIP 后再启动，避免只复制 EXE。

### 下载页显示 404

检查仓库地址与网络连接；私有仓库的 Release 需要授权，公开仓库的发布附件可直接下载。

### 文件显示失效

文件可能已被外部程序移动或删除。先检查实际路径，再移出旧映射并重新拖入。

### 桌面图标重叠或没有恢复

先通过托盘退出栖格，再检查 Windows 桌面右键 → 查看 → 显示桌面图标。不要为处理图标显示问题删除实际桌面文件。

## 卸载

- Setup 安装版：从 Windows“设置 → 应用”卸载栖格。
- 脚本安装版：先在设置中关闭开机启动，再通过托盘退出；删除 `%LOCALAPPDATA%\Programs\DeskNest`，以及桌面和开始菜单的快捷方式。
- 便携版：关闭开机启动并退出后，删除解压目录。

卸载程序文件后如需清除个人布局，再手动删除 `%LOCALAPPDATA%\DeskNest`；保留该目录便于之后重新安装恢复布局。

## 支持边界

单显示器是主要使用基线。多显示器、混合 DPI、Explorer 重启及桌面挂载降级需要结合具体系统实测。提交问题请提供复现步骤、Windows 版本和缩放比例，避免上传未脱敏的布局文件。
