# 栖格 · DeskNest 使用说明

## 安装与启动

1. 打开发布目录 `DeskNest-win-x64`。
2. 双击 `安装栖格.cmd`，软件会安装到 `%LocalAppData%\Programs\DeskNest`，并创建桌面与开始菜单快捷方式。
3. 也可以直接运行 `DeskNest.App.exe`，使用便携模式。

本轻量版本依赖 **Microsoft .NET 8 Desktop Runtime (x64)**。如果系统尚未安装，安装脚本会给出官方下载地址。软件不需要管理员权限。

## 基本使用

- **一键整理**：扫描当前用户桌面和公共桌面，按应用、文档、图片、文件夹与其他类型创建映射。
- **拖入分区**：从桌面或文件资源管理器把文件拖入盒子。
- **移动映射**：把盒子中的图标拖到另一个盒子。
- **打开**：双击映射图标。
- **更多操作**：右键图标可打开、定位或移出分区。
- **编辑分区**：拖动标题栏改变位置，拖动右下角改变尺寸，双击标题重命名。
- **锁定布局**：避免误拖动和误缩放。
- **隐藏原图标**：仅临时隐藏 Explorer 的图标列表，不移动文件；退出软件时恢复启动前状态。
- **退出**：右键系统托盘中的栖格图标，选择“退出”。

## 数据与隐私

布局保存在：

```text
%LocalAppData%\DeskNest\state.json
```

软件不联网、不上传文件名、不收集遥测。分区中的“清空映射、移出分区、删除分区”都不会删除真实文件。

## 卸载

1. 从托盘退出栖格。
2. 删除 `%LocalAppData%\Programs\DeskNest`。
3. 删除桌面和开始菜单中的“栖格 DeskNest”快捷方式。
4. 如需同时清除布局，删除 `%LocalAppData%\DeskNest`。

## MVP 限制

- 以单显示器为完整支持基线；多显示器使用统一虚拟桌面布局。
- Windows Explorer 大版本更新后若桌面嵌入失败，会自动使用安全置底模式。
- 真实文件被外部程序移动或删除后，映射会显示为失效，需要手动移出或重新拖入。
